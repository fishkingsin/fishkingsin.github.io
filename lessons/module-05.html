📋 步驟懶人包
👉 Voice 記事 → To-do List
  1. 打開 Gemini App，撳 mic icon 對話框右邊
  2. 就咁講你諗住要做嘅嘢 可以係雜務、idea、 shopping list
  3. 講完之後話：「幫我整理成 To-do List，按 priority 排好」
    📋 Copy幫我將以上嘅嘢整理成 To-do List， 按優先次序排好， urgent 標紅色，標埋建議日期。
👉 Long Text Summary
  1. 複製你想 summarize 嘅文字（WhatsApp / 文章 / Email）
  2. 貼落 Gemini，加呢句：
    📋 Copy請總結以下重點：最多 5 點，每點一句。 有 action item 請獨立列出。用繁體中文。
